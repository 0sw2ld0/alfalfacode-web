# alfalfacode.cuycoders.dev

Web estática de AlfalfaCode, publicada con GitHub Pages en https://alfalfacode.cuycoders.dev.

- `/`: AlfalfaCode, el agente de programación de código abierto.
- `/cloud/`: Alfalfa Cloud y sus códigos de cortesía.
- `/privacidad/`: aviso de privacidad y condiciones de Alfalfa Cloud.
- `/instalar.sh`: el instalador de la CLI (`curl -fsSL https://alfalfacode.cuycoders.dev/instalar.sh | sh`).
  Es una copia de `alfalfa/instalar.sh` de [AlfalfaCode](https://github.com/0sw2ld0/AlfalfaCode): no se edita aquí,
  se vuelve a copiar cuando cambia allí.

Antes vivía en `cuycoders.dev/alfalfa/`; esas direcciones redirigen aquí.

Sin compilación: HTML, CSS y un poco de JavaScript. Para verla en local:

```bash
python3 -m http.server 8791
```

Los colores salen de la app de Mac de AlfalfaCode (`alfalfa-mac/Sources/AlfalfaCode/Theme.swift`).
Las fuentes van servidas desde aquí; sus licencias están en `assets/fonts/LICENCIAS.txt`.
